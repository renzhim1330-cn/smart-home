# 07: 全系统固化烧录 (`main.py`)、AP热点手机控制与离线自启测试

**What to build:**
将所有模块装入发泡板沙盘内：将掌控板总成嵌在门禁柱方孔上，薄膜键盘贴在门边，充电宝平放在底座 5cm 暗格中，所有走线穿入暗格隐藏。使用 VS Code 将全功能工程源码上传重命名为掌控板根目录下的 `main.py`；拔掉电脑 USB 线，仅靠充电宝独立供电，掌控板开机 3 秒自动自启并广播 Wi-Fi 热点 `SmartHome-IoT`。评委或家长手机扫码连接，打开浏览器 `192.168.4.1`，完成键盘输入 `123456#` 开门、手机改密、PIR 防盗与 A 键 6 秒复位的全功能大联调。
