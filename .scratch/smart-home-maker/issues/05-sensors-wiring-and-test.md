# 05: DHT11 温湿度与 PIR 人体红外防盗模块接线与哈气联动测试

**What to build:**
将 DHT11 单总线数字温湿度传感器接在拓展板 P1 引脚（3.3V供电），将 PIR 人体红外热释电模块接在 P8 引脚；运行独立测试脚本 `test_sensors.py`，孩子用嘴向 DHT11 传感器哈一口热气，观察屏幕温度由 24℃ 瞬间跳变到 31℃ 并触发红灯告警；同时在 PIR 探头前挥手，观察屏幕显示“检测到人员移动”，掌握数据采集与逻辑判断全流程。

**Blocked by:** 02-standoff-stack-assembly

**Status:** ready-for-agent

- [ ] 连接 DHT11 模块：VCC 接 3.3V，GND 接 地线，DATA 数据线接拓展板 P1
- [ ] 连接 PIR 人体红外传感器：VCC 接 5V/3.3V，GND 接 地线，OUT 信号线接拓展板 P8
- [ ] 在 VS Code 中新建并运行 `test_sensors.py` 脚本
- [ ] 观察控制台与屏幕：每 2 秒刷新一次当前室内温湿度真实读数
- [ ] 少儿哈气测试：孩子凑近 DHT11 缓慢哈气，验证温度跃升超过 30℃ 时自动触发声光告警
- [ ] 人体防盗测试：人离开感应区等待 5 秒，再用手在探头前一晃，验证 P8 电平跳变为 1 并提示检测到入侵
