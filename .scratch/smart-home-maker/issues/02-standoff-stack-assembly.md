# 02: 掌控板与拓展板三铜柱螺丝“背靠背三明治”机械堆叠装配

**What to build:**
家长与孩子使用配件包中的 3 根双通隔离铜柱与 6 颗 M3 螺丝，将掌控板 2.0 与配套盛思拓展板背靠背对齐 3 个定位通孔，牢牢锁紧固定为一块厚度仅约 1.8cm 的刚性“三明治总成”。正面朝外显示 OLED 屏与按键，背面朝向室内引出引脚排针与独立供电接口，杜绝金手指插拔松动或插反烧板风险。

**Blocked by:** 01-vscode-environment-setup

**Status:** ready-for-agent

- [ ] 核对物料：掌控板2.0 1块、拓展板 1块、双通隔离铜柱 3根、M3盘头螺丝 6颗、十字螺丝刀 1把
- [ ] 辨识孔位：对准两块板子上的 3 个预留圆孔，将铜柱夹在两块板子中间作为支撑隔离
- [ ] 正反锁紧螺丝：使用小螺丝刀分别从正面和背面旋紧螺丝，要求平整不歪斜、晃动无松脱
- [ ] 供电点亮测试：将移动电源（充电宝）Type-C 线插在拓展板外接电源口，观察掌控板是否正常点亮，验证铜柱与排针电气连通正常
