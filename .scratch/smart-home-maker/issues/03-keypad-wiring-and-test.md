# 03: 3×4 矩阵薄膜键盘引脚接线与独立输入单元测试

**What to build:**
将 3×4 矩阵薄膜键盘的 7 根排线母头，按照行线与列线对应关系准确插入拓展板的数字 I/O 插针（P2, P3, P13, P14 为行，P15, P16, P4 为列）。运行独立测试脚本 `test_keypad.py`，家长和孩子在实体按键上按 0~9、*、#，能在屏幕上实时看到对应按键回显与按键蜂鸣声，并测试按 `123456#` 提示验证成功。

**Blocked by:** 02-standoff-stack-assembly

**Status:** ready-for-agent

- [ ] 按照“红/黑/蓝/绿”或排线线序，将 7 根排线分别插接到拓展板 P2, P3, P13, P14, P15, P16, P4
- [ ] 在 VS Code 中新建 `test_keypad.py`，录入轻量矩阵扫描测试程序
- [ ] 运行程序，在 3×4 薄膜按键上逐一按下 1 到 9 以及 0，验证屏幕实时显示按键字符并伴随清脆蜂鸣
- [ ] 测试按 `*` 键屏幕能清空输入，测试输入 `123456` 后按 `#` 屏幕显示“密码正确！”
- [ ] 用绝缘胶带将 7P 排线根部理顺固定，避免松脱
