# 04: SG90 舵机门梁顶置安装、5V独立供电接线与动作调试

**What to build:**
按照标准舵机三色线序口诀（棕色GND接地、红色VCC接外接5V动力电、黄色Signal接掌控板P0信号端），将 SG90 微型舵机安全接入拓展板；运行专用动作测试脚本 `test_servo.py`，测试舵机在 0°（大门紧闭）与 90°（大门全开）之间平顺旋转，验证大电流动作时掌控板系统不出现黑屏、重启或死机。

**Blocked by:** 02-standoff-stack-assembly

**Status:** ready-for-agent

- [ ] 辨别 SG90 舵机 3 根导线颜色与功能（红VCC / 棕黑GND / 黄橙Signal）
- [ ] 严格将红线插入拓展板的“外接 5V (Servo Power)”专用排针，黄线插 P0，杜绝接到掌控板 3.3V 脆弱引脚
- [ ] 在 VS Code 中新建并运行 `test_servo.py` 测试程序
- [ ] 观察舵机单字摆臂：开机自动平稳归位至 0 度；按空格或等待 3 秒后转到 90 度；再等待 3 秒自动回弹关门
- [ ] 验证独立供电稳定性：舵机快速转动时，掌控板 OLED 屏幕常亮无闪烁、无主控重启现象
- [ ] 用螺丝将单字白色摆臂轻轻固定在舵机金属/塑料齿轮轴上，标记 0 度和 90 度基准位置
